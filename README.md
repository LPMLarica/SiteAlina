# 💎 Site Dra. Alina Cardoso

Site profissional desenvolvido em Streamlit para a Dra. Alina Cardoso, especialista em Harmonização Orofacial, Facetas e Clareamento Dental.

## 📁 Estrutura do Projeto

```
site-alina-cardoso/
│
├── app.py                  # Aplicação principal
├── config.py              # Configurações e textos
├── style.css              # Estilos CSS
├── README.md              # Este arquivo
├── requirements.txt       # Dependências
│
└── assets/                # Pasta de imagens
    ├── logo_alina.png     # Logo da profissional
    ├── foto_alina.jpg     # Foto da profissional
    ├── projeto1.jpg       # Harmonização Orofacial
    ├── projeto2.jpg       # Facetas em Porcelana
    └── projeto3.jpg       # Clareamento Dental
```

## 📱 Funcionalidades

- ✅ Design responsivo e moderno
- ✅ Duas páginas de navegação
- ✅ Seção de projetos com cards interativos
- ✅ Página sobre com história e formação
- ✅ Links para Instagram e WhatsApp
- ✅ Animações suaves
- ✅ Efeitos hover elegantes
- ✅ Código modular e organizado

## 🛠️ Tecnologias Utilizadas

- **Python 3.8+**
- **Streamlit** - Framework web
- **Pillow** - Processamento de imagens
- **CSS3** - Estilização avançada
- **Google Fonts** - Tipografia Poppins
